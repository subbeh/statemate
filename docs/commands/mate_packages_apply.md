## mate packages apply

Sync packages

### Synopsis

Install missing packages. Use --prune to also remove packages not in config.

```
mate packages apply [flags]
```

### Options

```
  -h, --help    help for apply
      --prune   remove packages not in config (dangerous)
  -y, --yes     auto-confirm all changes
```
